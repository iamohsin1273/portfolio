04 Promote · flagship project

AI-Powered DevSecOps CI/CD Platform.

Context

A self-learnt project to prove out a secure, end-to-end delivery path for containerised applications — integrating the DevSecOps toolchain I work with into one automated pipeline, from commit to a running Kubernetes cluster.

What it does

  • Integrates GitHub, Jenkins, SonarQube, Trivy, Docker, Harbor & Kubernetes into one flow
  • Automates Kubernetes analysis for misconfig, failed workloads & resource constraints
  • Scans images and code quality before any deploy, GitOps-inspired
  • Adds OpenAI-powered diagnostics via K8sGPT with Slack notifications

Why it matters

Security and quality are enforced as gates, not afterthoughts — vulnerable images and low-quality code are caught before they reach the cluster. When something does go wrong at runtime, AI-assisted diagnostics shorten the path from incident to insight.

What I'd extend

  • Codify cluster & infra provisioning in Terraform and Ansible
  • Add Prometheus/Grafana dashboards and alerting on the deployed workloads
  • Promote across environments with automated rollback on failed health checks
